Real-time machine monitoring

By João Brighenti, founder of Mestti · Reviewed on 2026-10-29

Short answer

Machine monitoring means following, live, whether each machine is running, stopped, in a micro-stop or in setup, for how long, and how much it has produced. With sensors, this happens without anyone writing it down, and a stop shows up the moment it starts.

Running · Stopped · Micro-stop · SetupEach machine’s status, with time and reason.

Installed in 1 day, with no changes to the controls.

What you can see on each machine

  1. Status and time

    Running, stopped, micro-stop or setup, and for how long.

  2. Production

    Parts made, current order and actual cycle compared with the target.

  3. Stops with a reason

    The shift timeline, with the reason for each stop.

  4. OEE and cost

    Availability, performance, quality and the lost cost in money.

Walking the floor or a live screen?

Walking around and asking

  • You find the stop when you walk past the machine.
  • The reason depends on who remembers.
  • The day’s total only comes out at closing.

Live monitoring

  • The stop shows on screen the minute it starts.
  • The reason is entered on the tablet, right away.
  • The shift’s OEE and production are always up to date.

Where monitoring usually helps first

  1. Material shortage

    The same stop at the same time every day shows up on the timeline.

  2. Long setups

    Changeovers that exceed the standard become visible per machine and shift.

  3. Start of the shift

    Machines that take long to produce after switching on, as in the furniture case.

Questions about monitoring

Does it need internet all the time?

The sensor uses 2.4 GHz Wi‑Fi. If the connection drops, it stores the events and sends them when it returns.

What is a micro-stop?

A short stop, from seconds to a few minutes, that is almost never written down by hand. Added up over a shift, micro-stops can become hours.

Does monitoring watch the operators?

No. The sensor looks at the machine: count and whether it is running or stopped. People add the reason for stops.

Does it work on old machines?

In most cases, yes: the sensor reads count pulses, limit switches, linear measurement or the electrical signal, without a PLC. We assess each machine in the first conversation.

Is it for predictive maintenance?

Mestti focuses on production: count, status and stops. The current signal shows whether the machine is working; it is not vibration analysis. For maintenance, talk to the team about your case.
