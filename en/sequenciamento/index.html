Production scheduling: how to plan each machine’s queue

By João Brighenti, founder of Mestti · Reviewed on 2026-10-29

Short answer

Production scheduling sets the order in which operations go into each machine, respecting capacity, setup, priorities and the due date. Good scheduling shows, before starting, when each order should be ready and which one will be late.

Duration = cycle × quantity + setupAdded up in the machine’s queue, within the shift calendar.

Know which order will be late before it starts.

What goes into the calculation

  1. Capacity

    Each machine’s shifts, calendar and planned stops.

  2. Operation time

    Engineering cycle time, quantity, parts per cycle and setup.

  3. Constraints

    Do not start before, finish by, and alternative machines.

  4. Priority and due date

    The date promised to the customer and each order’s urgency.

Most common priority rules

No rule is always best. What matters is seeing the effect of each choice on due dates.

  1. First come, first served

    FIFO

    Simple and fair, but ignores the due date.

  2. Earliest due date

    EDD

    Reduces delays, but can increase setups.

  3. Shortest processing time

    SPT

    Finishes more orders sooner; long ones may wait too long.

  4. Group by setup

    Groups similar products and reduces changeover time.

Spreadsheet or visual scheduling?

In a spreadsheet

  • Dates are calculated by hand, with the time someone remembers.
  • Changing a priority means redoing the whole queue.
  • The delay shows up when the customer calls.

In visual scheduling

  • Duration comes from the cycle time recorded by engineering.
  • Each machine has its own queue on a timeline.
  • An order that goes past its due date is flagged before it starts.

Questions about scheduling

Is scheduling the same as APS?

APS (Advanced Planning and Scheduling) is the name for software that calculates schedules with finite capacity. Mestti shows each machine’s queue by capacity and calculates expected dates; the sequencing decision stays with the planner.

What is finite capacity?

It means scheduling knowing that each machine runs one operation at a time and has limited hours per day. The queue extends forward instead of piling everything on the same day.

What happens when a machine stops?

The stop shows up right away in monitoring, and the forecast for the running operation accounts for what is left to produce. Planning decides whether to change the sequence or the machine.

Can alternative machines be used?

Yes. Engineering defines which machines each operation can run on, and planning chooses when scheduling.

My factory is small. Does it make sense?

Yes. Even with a few machines, seeing the queue and each order’s expected date avoids promising dates blindly.
