Conhecer o Otto

Seis compromissos que estão no código.

O registro original não muda

O que o sensor enviou fica guardado como chegou. A operação trabalha sobre uma cópia organizada, e cada ajuste humano guarda autor e horário.

O passado não é reescrito

Correções valem daqui para frente. Mudar uma configuração hoje não altera os números de ontem.

Cada empresa isolada

Os dados de cada empresa ficam separados, e cada pessoa vê só o que o seu nível de acesso permite.

A IA pede licença

O Otto não escreve direto nos dados da fábrica. Ele propõe, simula e só executa depois da aprovação.

Sem internet, sem perda

Quando a conexão cai, o sensor guarda os eventos e envia depois. O período é reconstruído sem inventar dados.

“Sem sinal” não é “parada”

Falha de comunicação aparece como falha de comunicação. Ela não vira parada nem pune o operador.

O que perguntam sobre dados e segurança.

Ler os Termos de uso

Onde ficam os dados?

Na plataforma em nuvem da Mestti, com os dados de cada empresa separados. Detalhes de contrato estão nos Termos de uso.

Quem pode alterar um apontamento?

Quem tem permissão para isso. Cada alteração guarda quem fez e quando, e o registro original do sensor continua guardado.

A Mestti usa meus dados para outra empresa?

Não. Os dados de uma empresa não aparecem para outra, e o Otto só consulta os dados da empresa e do usuário que fez a pergunta.
